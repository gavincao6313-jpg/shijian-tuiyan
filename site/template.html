史鉴推演

纠结一个决定的时候，把你的处境说给它听。

它会从《史记》《资治通鉴》里找出走过同样局面的人，走对的和走错的都找，逐个推演每个选项的去向，最后给你一条带止损线的建议。

一个开源的 Claude Code 技能。历史给的是变量，不是答案。

四个示范推演

四个常见的抉择，每个都按同样的六步走完：立局、定母题、照镜、推演、换位、太史公曰。点开案例名，可以看到它在史书里的原貌。

个历史案例

按你正在经历的处境找。每个案例都写了它在什么条件下成立、什么条件下不成立，也标了这段史料有多可靠。

为什么可信

人生建议最怕两件事：拿编出来的典故讲道理，和只挑对自己有利的故事讲。下面是这两件事的防线。

怎么用

有三种用法：直接在这个页面填自己的 API Key；在本机打开页面，用你自己的 Claude 订阅额度；或者装成 Claude Code 技能，在 Claude Code 里说出你纠结的事，比如"帮我推演一下要不要辞职创业"。后两种都从下面这一行开始，装完就能用。

终端 · 一行安装
git clone --depth 1 __REPO__.git ~/.claude/skills/shijian-tuiyan

在 Windows 的 PowerShell 里，把 ~ 换成 $HOME。用 Codex 等其他 AI 工具的，克隆到任意目录，仓库根目录的 AGENTS.md 会告诉它怎么用。

想在两书全文里检索，或者改了案例要重跑引文校验，再下载原文语料。这一步可选，一两分钟：

终端 · 可选
cd ~/.claude/skills/shijian-tuiyan
pip install -r requirements.txt
python scripts/fetch_corpus.py
# 校验全部引文，应输出 FAIL 0 条
python scripts/verify_quotes.py

想在本机用订阅额度推演：先在终端登录一次 Claude Code，再启动本地页面。页面只在你的电脑上打开，对话框会通过本机的 claude 命令推演。

终端
# 只需一次：登录 Claude Code（用你的 Claude 订阅）
claude auth login
# 在后台启动本地页面，浏览器会自动打开 http://127.0.0.1:8765/
python scripts/serve_local.py --background
# 用完停止
python scripts/serve_local.py --stop

Windows 上不用敲命令：双击仓库里的 启动本地推演.bat，服务在后台运行，不占窗口；用完双击 停止本地推演.bat。
