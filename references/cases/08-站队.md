# 母题08 站队：派系、内斗与被迫表态

> 现代问题：公司内斗站哪边、新老板上来要不要表态、被拉入小团体、中立能不能活、收到"要命"的指令怎么办。
> 核心变量：①当下硬刚的收益 vs 保存实力后的收益 ②拉你的人给的是承诺还是恐惧 ③信息是否核实 ④长期名声的代价。

## 08-01 王陵面折，陈平周勃顺从
- 出处：史记·吕太后本纪
- 年代：前187
- 史料：A｜王陵被夺相权、陈平周勃后来诛诸吕都是公开事件
- 处境：吕后欲封诸吕为王，违背高祖「非刘氏而王，天下共击之」的白马之盟。
- 选项：A 当庭反对（王陵）／ B 暂时顺从、保存实力（陈平、周勃）
- 抉择：王陵当面反对；陈平、周勃表示同意。王陵退朝后责备二人，陈平答：
- 原文：「于今面折廷争，臣不如君；夫全社稷，定刘氏之后，君亦不如臣。」
- 结果：王陵被明升暗降为太傅，杜门不出；吕后死后，陈平、周勃联手诛灭诸吕，迎立文帝。
- 决定变量：当下反对改变不了结果，却会让你失去之后能改变结果的位置。
- 可迁移：面对一时无法扭转的错误决定，问自己：我是要"表明立场"，还是要"改变结局"？两者需要的策略相反。
- 对照：07-04 田丰
- 边界：顺从不能越过你的底线（陈平没有参与迫害刘氏）；而且你得确实在准备"之后"。否则顺从只是投降。
- 现代映射：新老板推一个你认为错误的方向，是当场反对还是留在位置上等待纠偏时机。

## 08-02 李斯沙丘之谋
- 出处：史记·李斯列传
- 年代：前210—前208
- 史料：B｜矫诏立胡亥是史记的说法；北大汉简《赵正书》记始皇临终同意立胡亥，有异说
- 处境：秦始皇死于沙丘，遗诏立扶苏。赵高拉李斯篡改遗诏立胡亥，理由是扶苏即位必用蒙恬为相，李斯将失位。
- 选项：A 拒绝，按遗诏办事 ／ B 与赵高合谋
- 抉择：李斯仰天流泪，最终同意。
- 原文：「嗟乎！独遭乱世，既以不能死，安托命哉！」
- 结果：胡亥即位后，赵高反手构陷李斯谋反，李斯被腰斩于咸阳，夷三族。
- 决定变量：驱动你站队的是"怕失去现有位置"；拉你入伙的人本身不可信，而你把把柄交给了他。
- 可迁移：因为恐惧而站队，是最差的站队。和一个肯做坏事的人合谋，你就成了他下一个要清除的知情人。
- 对照：02-04 李斯仓鼠论、17-04 魏豹（因一句预言站错队）
- 边界：若不站队本身就有生命危险，问题就不是"站谁"，而是"怎么走"。
- 现代映射：被拉入财务造假/内幕交易，理由是"你不参与，新领导来了你也保不住位置"。

## 08-03 扶苏：不核实就自尽
- 出处：史记·李斯列传
- 年代：前210
- 史料：B｜扶苏接诏自杀是公开事件；诏书是否矫诏，因《赵正书》的异说也有疑问
- 处境：扶苏在北边监军，接到伪造的赐死诏书。
- 选项：A 立即执行 ／ B 按蒙恬建议，先上书请求核实
- 抉择：扶苏认为父亲赐死不必再问，当即自杀。
- 原文：「父而赐子死，尚安复请！」
- 结果：扶苏死，蒙恬下狱后亦死；秦二世而亡。
- 决定变量：面对不可逆的决定，没有做成本极低的核实。
- 可迁移：凡是不可逆的决定（辞职、分手、断绝关系、卖掉资产），在执行前都值得做一次「复请」——哪怕你觉得结果必然如此。
- 对照：12 孤注
- 边界：核实也有成本（时间、被当作抗命），但与不可逆的损失相比通常很小。
- 现代映射：听到"老板要开除你"的传言就先提交辞职。

## 08-04 玄武门：临难不决，非勇也
- 出处：资治通鉴·唐纪七（武德九年）
- 年代：626
- 史料：B｜玄武门之变是公开事件；建成先谋害、世民再三犹豫的说法出自太宗过问后修成的实录
- 处境：太子李建成、齐王李元吉谋除秦王李世民，调走其精兵猛将，形势日危，部下力劝先发。
- 选项：A 继续忍让等父皇裁决 ／ B 先发制人
- 抉择：李世民犹豫再三，最终在玄武门伏兵先动手。
- 原文：「王今处事有疑，非智也；临难不决，非勇也。」（尉迟敬德劝谏语）
- 结果：李世民成为太子，两月后即位。
- 决定变量：对方已经开始削你的核心力量（调走部下），等待不再是中立，而是认输。
- 可迁移：分辨"冲突还能调和"与"对方已经动手"的信号——当对方开始系统地拆你的班底时，拖延就是选择。
- 对照：06-05 司马懿
- 边界：这是伴随杀戮的极端案例；现代情境只借鉴"识别对方已出手"与"不决之害"，手段必须合法。
- 现代映射：内部竞争对手已经在挖你的核心团队、截你的资源。

## 08-05 冯道：历事五朝
- 出处：资治通鉴·后周纪二（显德元年）
- 年代：954
- 史料：A｜历仕五朝、长居相位都是公开事件
- 处境：五代乱世，朝代更迭频繁。冯道不站任何一方，谁掌权便侍奉谁，历仕五朝（含辽）八姓十余位君主，长期身居相位。
- 选项：A 为某一方殉节 ／ B 不站队，谁来跟谁
- 抉择：始终不站队，自号「长乐老」，七十三岁善终。
- 原文：「朝为仇敌，暮为君臣，易面变辞，曾无愧怍。」（臣光曰）
- 结果：个人及家族平安富贵，也在乱世中保全过一些百姓；但被司马光、欧阳修痛斥为无廉耻。
- 决定变量："不站队"在高度动荡期能活下来；代价是长期名声与信任。
- 可迁移："谁都不得罪"是一种可行的生存策略，但你要清楚它的价格：没有人会在关键时刻为你站出来，你的历史评价由别人写。
- 对照：02-06 魏征
- 边界：动荡期与稳定期不同；在稳定组织里做"老好人"通常得不到冯道那样的回报。
- 现代映射：在频繁换帅的公司里做一个谁来都能合作的中层。
