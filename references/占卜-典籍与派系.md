# 占卜专题背景：历代典籍、派系与演变

> 这份是母题 17「占卜」的背景资料。用户提到八字、紫微、六爻、风水、黄历时，可以从这里查它是哪一门、出自哪类书、有哪些派系分歧。
> 推演时不从这里引古文。古文只能逐字摘自案例的「原文」字段，或 `grep_source.py` 的检索结果。这份资料不判术数真假，也不替人算命。

## 一、先看清全貌

各门术数共用一套底层：阴阳五行、天干地支、八卦。派系之间的分歧主要在两处，一是**拿什么当输入**，二是**用哪套规则解读**。输入可以是龟甲裂纹、蓍草、铜钱、出生时间、面相、地形、星象。

古人自己有两种分类：
- 《汉书·艺文志·数术略》分六类：天文、历谱、五行、蓍龟、杂占、形法。
- 《四库全书》术数类分七属：数学、占候、相宅相墓、占卜、命书相书、阴阳五行、杂技术。四库馆臣的总评，大意是这些都是易学的旁支，又掺进了各种杂说。

现在常说的"五术"（山、医、命、相、卜）是近现代港台的提法，古代目录书里没有。

## 二、按输入分九门

| 门类 | 输入 | 代表典籍（大致从早到晚） | 派系 |
|---|---|---|---|
| 卜筮·易占 | 龟甲裂纹、蓍草、铜钱、数字 | 甲骨卜辞 →《周易》《易传》→ 焦延寿《焦氏易林》、京房《京氏易传》→《火珠林》→《梅花易数》→ 清《增删卜易》《卜筮正宗》 | 大衍筮法、纳甲六爻（俗称文王课）、梅花易数 |
| 三式 | 问事那一刻的时间，用来起局 | 太乙：唐王希明《太乙金镜式经》；奇门：《烟波钓叟歌》、明程道生《遁甲演义》；六壬：《黄帝龙首经》、宋凌福之《毕法赋》、明《大六壬指南》《六壬大全》 | 俗话说太乙测天（国运），奇门测地（兵事方位），六壬测人（人事） |
| 命理 | 出生时间 | 八字：《渊海子平》《三命通会》《子平真诠》《滴天髓》《穷通宝鉴》；紫微斗数：《紫微斗数全书》；七政四余：明万民英《星学大成》、《果老星宗》；神数：铁板神数、邵子神数 | 派系最多，见下节 |
| 相术 | 面、手、骨、声、气色 | 《左传》已有相人记载，《荀子·非相》是最早的系统批判 →《太清神鉴》、金张行简《人伦大统赋》→《麻衣神相》、明袁珙与袁忠彻父子的《柳庄相法》《神相全编》→《冰鉴》（旧题曾国藩） | 麻衣、柳庄两大系统，派系之分不明显 |
| 堪舆风水 | 地形、方位、时间 | 《葬书》（旧题郭璞，"风水"一词出自此书）→ 杨筠松《撼龙经》《疑龙经》→ 明《地理人子须知》→ 清蒋大鸿《地理辨正》、赵九峰《地理五诀》、《八宅明镜》、沈竹礽《沈氏玄空学》 | 派系多，见下节 |
| 天文星占 | 星象、云气、风 | 《甘石星经》→《史记·天官书》→ 李淳风《乙巳占》→ 瞿昙悉达《开元占经》（120 卷） | 朝廷垄断，民间没有派系 |
| 择日 | 某一天的宜忌 | 秦简《日书》→ 唐吕才刊定的阴阳书 → 清代官修《协纪辨方书》→《玉匣记》、通书、老黄历 | 神煞通书、正五行、天星、奇门择日 |
| 杂占 | 梦、字、签、身体异象 | 占梦：敦煌本《周公解梦书》、明陈士元《梦占逸旨》；测字：宋代谢石；签：观音灵签、关帝灵签；另有扶乩、称骨、鸡卜 | — |
| 谶纬预言 | 预言文本 | 汉代纬书（"七纬"）→《推背图》《马前课》《烧饼歌》 | 几乎全是托名、事后附会，版本越晚出越"准" |

**为什么民间术数几乎都在算个人前程**：中国的天文星占是"军国星占"，只占国家大事，由朝廷垄断。唐律规定，私藏天文图书和太一式、雷公式的，判徒刑两年；三式里只有六壬允许民间使用。用星盘推个人命运的生辰占星，反而是唐代经印度、波斯传进来的（《聿斯经》，后来发展成七政四余）。民间能放开发展的只剩命、相、卜、宅、择日这几门。

## 三、派系分歧最大的四块

**1. 易学：四库总结的"两派六宗"**
- 象数派分三宗：
  - 占卜宗：《左传》里的筮法
  - 禨祥宗：京房、焦延寿，讲灾异吉凶
  - 造化宗：陈抟、邵雍。邵雍的《皇极经世》用"元会运世"推算历史周期
- 义理派分三宗：
  - 老庄宗：王弼，主张"扫象"
  - 儒理宗：胡瑗、程颐
  - 史事宗：李光、杨万里《诚斋易传》，用史事解卦。史鉴推演和它最近，区别是按母题组织案例、逐字校验，不靠卦象
- 后来的发展：
  - 朱熹认为《周易》本来就是卜筮之书，想把两派合起来。
  - 民国时，顾颉刚《古史辨》第三册、高亨《周易古经今注》把《周易》还原成占筮记录。
  - 张政烺认出了商周器物上的"数字卦"。
  - 出土文献有上博简《周易》（现存最早的版本）、王家台秦简《归藏》、清华简《筮法》，补回了一部分失传的筮法。

**2. 八字（子平术）**
- 古法：以年柱为主，看重纳音和神煞。唐代李虚中用年、月、日三柱推命，韩愈为他写过墓志。
- 子平法：五代宋初的徐子平改为以日干为"日主"，四柱八字从此定型。后来分成四派：
  - 格局派：清沈孝瞻《子平真诠》
  - 旺衰（扶抑）派：《滴天髓》，以及清任铁樵的《滴天髓阐微》
  - 调候派：清余春台编订的《穷通宝鉴》
  - 病药派：明张楠《神峰通考》
- 民国：徐乐吾、袁树珊、韦千里常被并称为三大家。
- 当代：盲派由段建业等人整理盲人师傅的口传，看重"取象"和"做功"；台湾有梁湘润的传统派，何建忠提出"八字心理推命"。
- 同一个八字，不同派常给出不同结论，所以先问清对方是哪一派。参照案例 17-15 七家择日。

**3. 紫微斗数**
- 托名宋初陈抟。现存最早的文本是明万历《续道藏》收录的《十八飞星策天紫微斗数》。
- 流派大多是 20 世纪在台港形成的：
  - 三合派：看星曜组合和格局
  - 四化飞星派：看宫位之间的四化飞化
  - 中州派：香港王亭之
  - 透派：台湾张耀文

**4. 风水**
- 形势派，又叫峦头派、江西派，始于唐末杨筠松，看龙、穴、砂、水。
- 理气派，又叫福建派，始于宋代王伋，看罗盘方位和时间，下面再分三派：
  - 三元派：玄空飞星、玄空大卦，二十年换一运；代表人物有蒋大鸿、章仲山（无常派）、沈竹礽
  - 三合派：用十二长生水法，代表作《地理五诀》
  - 八宅派：把人分成东四命、西四命，代表作《八宅明镜》
- 行内的共识是"峦头为体，理气为用"。当代香港最流行的是玄空飞星。

## 四、从古到今的演变

| 时代 | 关键变化 |
|---|---|
| 商 | 用龟甲兽骨占卜，以王室为主 |
| 西周 | 出现蓍草筮法，《周易》卦爻辞成形，龟卜和蓍筮并用；《洪范》的稽疑规则见 17-16 |
| 春秋战国 | 《左传》《国语》留下二十多个筮例；星占、相人、《日书》择日流行；阴阳五行学说成为后来多数术数的底层 |
| 秦汉 | 京房纳甲，是六爻的源头；谶纬预言卷入政治（17-05、17-10、17-13）；汉墓出土过六壬式盘；风水开始萌芽 |
| 魏晋南北朝 | 王弼扫象，易学转向义理；管辂、郭璞成了术士的代名词（17-11） |
| 隋唐 | 太卜署掌管三式（当时指雷公、太一、六壬，宋以后改为太乙、奇门、六壬）；李虚中用三柱推命；杨筠松开创风水形势派；西方占星传入；吕才奉命刊定阴阳书（17-14） |
| 宋 | 转折期：八字定型，用铜钱起卦的《火珠林》流行，邵雍发展象数，风水分出江西、福建两派，测字和灵签兴起。科举取士大增、印刷普及，"问功名"成了大众需求 |
| 明清 | 大量托名书出现（梅花易数、紫微斗数、铁板神数）；清廷官修《协纪辨方书》统一择日标准；《四库》收录术数，同时把它定性为易学旁支 |
| 民国 | 出现命理三大家；学界疑古，把《周易》当作占筮史料来研究 |
| 1949–1980 | 大陆中断，台港和南洋继续传承并商业化，紫微斗数和风水的现代流派大多在这时成形 |
| 1980–90 年代 | 大陆出现"周易热"，与气功热同期 |
| 2025 年起 | AI 算命走红，用大模型排八字、解卦 |

## 五、两条提醒

**注意托名**：鬼谷子、诸葛亮、李淳风、袁天罡、陈抟、邵雍、刘伯温，这些名字在术数书上基本是招牌，不等于真正的作者。比如《梅花易数》大约成书于明代；《滴天髓》旧题宋代京图撰、刘基注，作者至今有争议。

**"不信派"也有一条完整的传承**：
1. 荀子《非相》：看人长相，不如看他的心思和做法
2. 韩非《饰邪》：龟策鬼神不能保证打胜仗
3. 王充《论衡》：卜筮、讥日、诘术、辨祟等篇逐条反驳
4. 唐代吕才：用史书回测禄命、宅经、葬书（17-14）
5. 司马光《葬论》：反对风水。他自己仿《太玄》作过《潜虚》，可见他反对的是葬书，不是易学
6. 四库馆臣

## 六、延伸阅读

- 李零《中国方术考》《中国方术续考》：结合出土文献讲方术史
- 江晓原《星占学与传统文化》：军国星占和生辰占星的区别
- 黄一农《社会天文学史十讲》：择日、星占怎样卷进政治
- Richard J. Smith《Fortune-tellers and Philosophers》：清代社会里的占卜
- 尚秉和《周易古筮考》：历代筮例汇编，大多附有结局，可以从中找新案例（入库前照样要用 `grep_source.py` 核对原文）
